# 작업 도구 — 시험대·러너·검증 (옛 기록)

CLAUDE.md 에서 옮겨 온 기록이다(2026-10-14). 지금은 `tools/harness.sh`(스킬 `시험대`)·스킬 `조문다시만들기`·`법령검증` 이 이 일을 한다. 경로 `scratchpad/uitest/` 는 옛 자리다.

- **화면은 시험대에 띄워서 눈으로 본다.** `scratchpad/uitest/` 에 app.js·style.css·
  index.html 을 복사해 두고, Supabase 를 흉내 내는 껍데기(`mocksb.js`)와 사용자
  백업에서 뽑은 자료(`mockdata.js`)를 물린다. **로그인 없이 여섯 탭이 다 그려진다.**
  `?tab=laws&ask=1` 로 AI 결과창을, `?art=1` 로 조 원문 창을 바로 띄운다.
  헤드리스 크롬으로 900px·620px 을 찍어 보면 「0건이 없어요」·범례 불일치 같은 것이
  스샷 부탁 없이 잡힌다. (실제 세션 발급은 막혀 있다 — 흉내 껍데기로 충분하다.)

- **「조문 전부 다시 만들기」도 대신 눌러 줄 수 있다.** `scratchpad/uitest/runner.html` —
  Supabase 를 **진짜로** 부르는 껍데기(`realsb.js`, service_role 열쇠)를 물리고 app.js 를
  그대로 실행해 `lawBuildAll(true)` 를 부른다. 원본 PDF 는 미리 받아 `pdfmap.js` 로
  이어 준다. **흉내 낸 코드가 아니라 앱의 진짜 코드가 돌아** 결과가 앱이 만드는 것과 같다.
  - Chrome 은 `--headless=new` 로 띄운다. `--virtual-time-budget` 을 주면 가상 시계가
    먼저 다 흘러 **일이 끝나기 전에 종료**된다.
  - **시험대의 app.js 를 최신으로 복사했는지 반드시 확인한다** — 옛 판으로 한 번 통째로
    다시 만들어 놓고 「왜 안 고쳐졌지」를 한참 찾았다.
  - 쓰기 전에 `law_articles`·`law_pages` 스냅샷을 뜬다(`snapshot_law.json.gz`).
    데이터 백업(JSON)에는 조문 글자가 없다.
  - **다시 만드는 동안 사용자가 「전체 보기」를 누르면 「조문을 찾지 못했어요」가 뜬다** —
    조문 id 가 지워졌다 새로 생기기 때문이다. 미리 알린다.
- **검증은 낱말 55개로 한 번에 돌린다** (`scratchpad/uitest/verify.py`). 라벨↔원문이
  아귀가 맞는지 기계로 본다. **검사기의 오탐부터 의심한다** — 전화번호 043-719-3650 을
  쪽 번호로, 「별표 N · 절 제목」을 머리말 불일치로 잡았다.
